# Cleuseau Quick Reference

[cleuqr.pdf][] is a recreation of the quick reference pamphlet for the
Cleuseau ROM for the TRS-80 Model 100/102, Tandy 200, NEC PC-8201. The
[original scan][] was hard to read so hackerb9 retyped it and made it
available UTF-8 text, M100 text, and PDF.

[original]: original_scan.pdf

## Files 

* [cleuqr.pdf][]: The Cleuseau ROM Quick Reference in PDF format.
  Print to a double-sided sheet of US Letter paper to create a
  tri-fold pamphlet.
